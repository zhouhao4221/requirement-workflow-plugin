> 版本范围：v2.40.0..HEAD

## 新功能

- **feat(QUICK-003): `/req:do`、`/req:fix` 增加固定验证步骤，抽成 `shared/_verify.md`**
  - 新增 `shared/_verify.md`：方案每个单元附「验收」行（可执行命令或可观察行为），同时作为 `impl-worker` 委派准入第四条的凭据；固定验证顺序「编译/lint → 相关测试回归（派 `test-runner`）→ 覆盖判断」，覆盖缺失按意图类型分流：小功能/修复询问补 UT，优化/重构/升级/规范记「无测试覆盖」并派生手动验证清单
  - 失败处理：测试失败最多修 2 轮，仍失败停下把失败清单交给用户；红线是不得改断言、跳过或删用例让测试通过，唯一例外是方案「行为变化」行已声明且用户确认
  - 完成提示固定「验证结果」段（编译 / lint / 测试 / 无测试覆盖 / 手动验证 / 测试改动），缺项写「未配置」，整段不得省略；`/req:commit` 采信此段不重跑
  - `do.md`：规模判断在 `code-scout` 返回后复核一次；无 issue 但当前在 `mainBranch`/`developBranch` 时按类型前缀建分支，不在主线直接改；新增步骤 3.5 验证
  - `fix.md`：修复建议加验收行；`--auto` 下「是否补 UT」按否处理
  - `test_new.md`：新增 `--files=<源文件>` 无文档模式（仅 `--type=ut`），供 do/fix 补 UT 时调用；测试规范来源改为 `docs/prompt/testing.md`，缺失回退 `architecture.md`
